# Evaluation Scripts (Archived)

Superseded evaluation scripts from earlier project phases. These have been replaced by the active evaluation pipeline in `/scripts/evaluation/`.

## Subdirectories

**`root/`** -- Evaluation scripts that originally lived in the project root directory. Moved here during the repository reorganization to clean up the top-level structure.

**`scripts_dir/`** -- Evaluation scripts that originally lived in the `scripts/` directory. Superseded by newer versions in `/scripts/evaluation/` that support the current environment wrappers and constraint definitions.

## Active Evaluation Code

Do not use the scripts in this archive for new evaluations. The active evaluation scripts are in:

```
/scripts/evaluation/
```

These archived scripts may reference old environment variable names, outdated constraint channel numbering, or deprecated observation formats.
